# Machine Learning Assignments

Code for all 10 Machine Learning assignments.

| # | Aim | File | Dataset |
|---|-----|------|---------|
| 1 | Association between dependent and independent variables | `assignment_01.py` | Advertising (Kaggle) – `advertising.csv` |
| 2 | Clustering (unsupervised learning) | `assignment_02.py` | Mall Customers (Kaggle) – `Mall_Customers.csv` |
| 3 | Dimensionality reduction using PCA | `assignment_03.py` | Wine (built into scikit-learn) |
| 4 | Naive Bayes classification | `assignment_04.py` | Breast Cancer (built into scikit-learn) |
| 5 | KNN classification | `assignment_05.py` | Iris (built into scikit-learn) |
| 6 | Linear Regression | `assignment_06.py` | Synthetic (generated in code) |
| 7 | SVM for Regression | `assignment_07.py` | Synthetic (generated in code) |
| 8 | Regularization to avoid overfitting | `assignment_08.py` | Synthetic (generated in code) |
| 9 | Object detection from CCTV footage | `assignment_09.py` | Any sample video saved as `cctv.mp4` |
| 10 | Fake news detection from multimodal data | `assignment_10.py` | Fakeddit – `multimodal_train.tsv` |

## Run
```
pip install -r requirements.txt
python assignment_03.py
```
Assignments 1, 2, 9 and 10 need their dataset/video downloaded first (links are at the top of each file).
